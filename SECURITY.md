# Security

Please report a security problem privately to [support@ostgate.app](mailto:support@ostgate.app)
with "Security" in the subject, not as a public issue. Include the Ostgate version
(Ostgate > About Ostgate), your macOS version, and the steps to reproduce.

Only the latest release receives fixes.

How Ostgate handles sign-in, keys, local listeners and network traffic, and which hosts it
contacts: [ostgate.app/security](https://ostgate.app/security).
